# Yusuf Arca Çiçek — Portfolio

Static bilingual portfolio website.

## Open the project

This project does **not** require a build step.

### Option 1 — easiest
Open `index.html` directly in your browser.

### Option 2 — VS Code
Open the folder in VS Code and run it with the **Live Server** extension.

### Option 3 — local server
If you have Python installed:

```bash
python -m http.server 5500
```

Then open:

```txt
http://localhost:5500
```

## Included

- English / Turkish language toggle
- Cinematic hero section
- Animated reveal effects
- Cursor glow / spotlight hover / tilt panel
- Project section
- Experience & education section
- Skills section
- Contact section
